# Canopy

Canopy is a native macOS app for understanding and managing Claude Code and
Codex configuration. It visualizes local settings, provides focused GUI editors
instead of requiring manual JSON or TOML changes, and connects supported AI
clients through a local MCP integration.

## Download

[Download the latest Canopy DMG](https://github.com/Tackrow/Canopy/releases/latest/download/Canopy-latest.dmg)

Canopy requires macOS 26 or later. Release builds are signed with a Developer ID
certificate and notarized by Apple.

## Updates

Automatic updates use Sparkle. Update archives are cryptographically signed so
Canopy can verify them before installation.

## Privacy

Canopy is local-first. Configuration discovery, visualization, editing, and MCP
operations keep data on your Mac by default. You remain in control of the
directories Canopy manages and the changes it applies.
